# Phassakorn Personal Profile Website

เปิด `index.html` ในเบราว์เซอร์ได้ทันที

ไฟล์หลัก:
- index.html — เว็บไซต์หน้าเดียว Responsive
- style.css — Modern UI / animations / dark mode
- script.js — scroll reveal, counters, theme toggle, TH/EN toggle
- documents/Phassakorn_Resume.pdf — Resume ฉบับย่อ
- documents/Phassakorn_CV.pdf — CV ฉบับเต็ม

หมายเหตุ:
- ปุ่ม Download Resume และ Download CV เชื่อมกับ PDF ในโฟลเดอร์ documents
- เว็บไซต์ไม่ต้องใช้ backend
- หากอัปโหลดขึ้น hosting ให้คงโครงสร้างโฟลเดอร์เดิม
